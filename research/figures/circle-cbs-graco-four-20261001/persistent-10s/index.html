Slowing the cadence did not establish a common frame across all four robots within 30 iterations. A05, A07 and G05 publish in A05's frame, while G06 still publishes in A07's frame. The local geometry checks can pass despite this global inconsistency. No four-robot joint ATE is reported because the common-frame gate failed; no external alignment repairs the result.

This reproduces the reference-propagation failure at a slower cadence. The logged computation fits comfortably within 10 seconds, so optimizer callback overrun does not explain this run's failure. Code inspection shows that the persistent GLOBAL marginal removes incoming anchor-belief factors and persistent responses do not relay those anchors. This is consistent with failure to carry A05's reference through the A05–A07–G05–G06 chain; repairing that mechanism is separate from this cadence test.

This test changes only the execution mode, cadence, settling count and timeout. The native optimizer binaries, PCM policy, GPU registration settings, verified loops and point geometry match the sealed experiment. Each robot's timer callback is mutually exclusive. Peer belief requests remain asynchronous, with one outstanding request per peer. The requested 10 seconds is a scheduling interval, not solve time.
